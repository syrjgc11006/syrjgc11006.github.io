What is ptblog

A full-stack learning-resources platform designed and developed by an industrial software engineer. It is not a static brochure — it ships with a Node.js backend, MySQL persistence, H5 and mini-program clients, an admin panel, and AI-powered document tools.

  • Long-form technical articles & interview banks for .NET / WPF / Redis / MySQL / Go
  • Hands-on tutorials & weekly engineering notes from real projects
  • Deep-dives into protocols, performance tuning and architecture practice
